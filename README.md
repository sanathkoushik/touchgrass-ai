# TouchGrass AI

An open-weight personal AI agent that learns what genuinely motivates a person and designs small, realistic real-world experiences they are likely to choose over passive screen use.

> Social platforms learned what keeps each person on a screen. TouchGrass AI learns what gets each person off it.

## Status

Under construction, built in stages. See [docs/MVP.md](docs/MVP.md) for scope and non-goals.

## Planned stack

React + Vite + TypeScript, Tailwind CSS v4, shadcn/ui, Motion, Cloudflare Workers + Hono, Gemma 4 via Workers AI, MongoDB Atlas (free), Open-Meteo.
